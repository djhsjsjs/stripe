# Платный триал в Stripe: $3 за 7 дней → $30/неделю

Это готовый минимальный проект. В нём два файла:

- `api/create-subscription.js` — "кассир": секретный сервер, который создаёт подписку в Stripe. Секретный ключ живёт только здесь.
- `public/checkout.html` — страница оплаты, которую видит пользователь (её можно скопировать в свой лендинг).

## Шаг 1. Настрой Stripe (если ещё не сделал)

1. В Stripe Dashboard → **Products** → создай продукт.
2. Добавь к нему **две** цены:
   - Recurring, $30.00, раз в 1 неделю → это `WEEKLY_PRICE_ID`
   - One-time, $3.00 → это `TRIAL_PRICE_ID`
3. В **Developers → API keys** скопируй `Secret key` (`sk_test_...`) и `Publishable key` (`pk_test_...`).

## Шаг 2. Разверни backend на Vercel (бесплатно, без консоли)

1. Зайди на **vercel.com**, зарегистрируйся (можно через GitHub или просто email).
2. Нажми **Add New → Project → Deploy without Git** (или залей эту папку к себе на GitHub и импортируй репозиторий — оба варианта работают).
3. Загрузи содержимое этой папки (`stripe-trial`) целиком.
4. После создания проекта зайди в **Settings → Environment Variables** и добавь:
   - `STRIPE_SECRET_KEY` = твой sk_test_...
   - `WEEKLY_PRICE_ID` = price_... (еженедельная цена $30)
   - `TRIAL_PRICE_ID` = price_... (разовая цена $3)
5. Нажми **Redeploy**, чтобы переменные применились.

После деплоя Vercel даст тебе адрес вида `https://твой-проект.vercel.app`.

## Шаг 3. Подключи публичный ключ

Открой `public/checkout.html`, найди строку:

```js
const stripe = Stripe('pk_test_ВСТАВЬ_СВОЙ_КЛЮЧ');
```

и вставь свой `Publishable key`. Этот ключ **не секретный**, его можно спокойно оставлять в коде страницы.

## Шаг 4. Проверь

Открой `https://твой-проект.vercel.app/checkout.html`, введи email и имя, затем тестовую карту:

```
4242 4242 4242 4242, любая будущая дата, любой CVC
```

В Stripe Dashboard → Customers появится клиент со счётом на $3.00 (оплачен) и подпиской в статусе `trialing`. Через 7 дней (в тестовом режиме это можно "перемотать" через Dashboard → Test clocks) статус станет `active`, и начнутся списания $30 каждую неделю.

## Когда всё протестировано и готово к реальным деньгам

1. Переключи Stripe Dashboard с Sandbox на боевой режим (кнопка "Переключиться на реальный счёт" на скриншоте).
2. Повтори шаги создания продукта/цен уже в боевом режиме — тестовые и боевые данные в Stripe разделены.
3. В Vercel замени `STRIPE_SECRET_KEY`, `WEEKLY_PRICE_ID`, `TRIAL_PRICE_ID` на боевые (`sk_live_...` и боевые `price_...`), и `pk_test_` в HTML на `pk_live_...`.

## Важно про честность оферты

Обязательно оставь на странице заметный текст о том, что после пробного периода будет списываться $30 в неделю (в `checkout.html` он уже есть внизу формы, мелким шрифтом — как в твоих референсах). Платёжные системы и банки блокируют аккаунты, если сумма и периодичность списаний не были явно показаны пользователю до оплаты.
